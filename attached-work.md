# Attached-work preparation is retired

This flow no longer exists. A chat's **Changes** view only lists its edits; it is
never a request or an approval.

If you were started to prepare attached work from a chat's Changes view:

1. Make no changes. Do not stage, edit or settle anything, and do not run
   `settle_chat_changes.py` (it no longer exists).
2. Report back to the owner in one short message: this preparation path is
   retired; to prepare the conversation's changes, ask that conversation to
   prepare them, or use **Prepare** for the project in Contribute.

This stub exists only so older Möbius builds that still start this flow get a
clear answer for one release window. Remove it after that window.
